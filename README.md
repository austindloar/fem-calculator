# Calculator
This project is based off of the [Complete Intro to Web Development, v3](https://master.dev/courses/web-development-v3/)
course hosted on master.dev. The goal of this project was to create a simple
four-function calculator that worked in the browser, mimicing the design of the
native iOS calculator. This project exercised skills in both HTML and CSS
through the layout and design of the webpage, as well as JavaScript in the logic
and scripting of the calculator itself.

The webpage is hosted using GitHub Pages [here](https://austindloar.github.io/fem-calculator).
